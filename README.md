# PC Part Picker

L'app che abbiamo sviluppato serve per comporre e salvare una build di computer per poi esportarle in pdf o txt.

## Funzionalità Presenti:

- Login/registrazione

- creazione della build
- salvataggio della build nel profilo dell'utente
- modifica delle build salvate
- esportazione delle build
- localizzazione ita/eng
- tema chiaro/scuro
- Barra di ricerca
- gestione dell'account
